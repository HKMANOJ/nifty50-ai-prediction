3. CORE FEATURES & WHAT WE ACHIEVED
================================================================================

3.1. Zero-Cost Real-Time Data Pipeline
- Built an automated data fetcher communicating directly with NSE India's official
  market data endpoints and Yahoo Finance Intraday chart engines.
- Zero subscription cost: No paid API keys (TradingView Pro, Zerodha Kite API, etc.)
  are required.

3.2. One-Side Rally & F&O Breakout Detection Engine
- Cross-References NSE F&O Top 20 Gainers/Losers with OI Spurts (Change in Open Interest).
- Classifies each stock into clear institutional setups:
    • Long Buildup: Price UP + OI UP (Institutional Buying)
    • Short Covering: Price UP + OI DOWN (Shorts Forced to Cover)
    • Short Buildup: Price DOWN + OI UP (Institutional Selling)
    • Long Unwinding: Price DOWN + OI DOWN (Longs Liquidating)
- Calculates One-Side Rally Score (0 - 100) based on:
    • Range Position Hold (Price sustaining in upper/lower 25% of the day)
    • Move from Open (Clean directional expansion)
    • Volume Multiple & Relative Volume (RVOL)
    • Breakout Timestamp tracking (e.g. 09:30 AM)

3.3. Vardhaan Capital UI / UX Workstation Design
- Exact replication of the Vardhaan Capital StockHunter Pro layout:
    1. Dark Sidebar: Navigation tabs (Futures & Options, Intraday Momentum, Heatmaps).

       - Advance / Decline Ratio (20 Adv / 20 Dec)
       - Opening Range Breakout Count (18 Up)
       - NIFTY PCR (Put-Call Ratio) & Fear & Greed Sentiment
    3. Split Workstation View:
       - Left Scrollable Candidate List: Ranked stocks with %, setups, and badges.
       - Right Chart Panel: Responsive TradingView chart with dynamic symbol info.

4. DETAILED TECHNICAL IMPLEMENTATION (HOW WE ACHIEVED IT)
================================================================================

4.1. Overcoming NSE Anti-Scraping & 429 Rate Limits
- Problem: Direct requests to NSE and Yahoo Finance query1 endpoints frequently returned
  HTTP 403 Forbidden or HTTP 429 Too Many Requests.
- Solution: 
  - Implemented session handshake emulation using real desktop Chrome User-Agent headers,
    standard browser headers (`Accept: text/html,application/json`), and correct referer.
  - Upgraded Yahoo Chart base to `query2.finance.yahoo.com/v8/finance/chart` which provides
    seamless, unthrottled access to 5-minute Indian market equity candles.

4.2. Algorithmic Filtering (OI Spurt + Top Gainers/Losers Overlap)
- Located in: `stock_suggestion_index.py`
- Only stocks that appear simultaneously in BOTH the F&O Top Gainers/Losers and the OI
  Spurt lists are qualified as high-probability breakout candidates.
- Generates dynamic Trade Plans, Target levels, Stop-Loss triggers, and Breakout Timestamps.

4.3. Multi-Day 5-Minute Candlestick Streaming
- Updated `fetch_5m_candles_for_symbol(symbol, full_range=True)` to extract and format
  all available 5-minute bars over the past 5 trading days.
- Output timestamps are formatted in UTC/epoch seconds with strict ascending ordering to
  ensure flawless TradingView time-scale indexing.

4.4. Pinned TradingView Lightweight Charts & Zero Latency
- Problem: Unpinned CDN requests pulled Lightweight Charts v5.2.1 which deprecated
  `addCandlestickSeries()`, causing blank canvases.
- Solution: 
  - Pinned and downloaded `lightweight-charts@4.2.1` directly into a local file
    `lightweight-charts.standalone.js`.
  - Added ResizeObserver and fallback loading logic so the chart initializes instantly
    regardless of internet speed or CDN availability.
